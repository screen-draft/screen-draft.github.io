AI API 접속 키 보호

AI API에 접속 키가 필요하면 키를 화면 코드에 넣지 않습니다. 화면에 들어간 키는 방문자 누구나 볼 수 있어 사용료가 도용될 수 있기 때문입니다. 작은 중계 서버가 키를 보관하고 대신 호출합니다.

방문자 브라우저키 없음→중계 서버키 보관, 호출 횟수 제한→귀사 AI API
